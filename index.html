How this works
  1. Scroll to the bottom-left of the page and paste in a free YouTube Data API key — that's what lets this page fetch real video data from YouTube.
  2. Don't have one? Click "Get a free key" down there, enable "YouTube Data API v3" in Google Cloud Console, then create an API key. No billing needed.
  3. Use the box at the top to add creators by URL, @handle, or channel ID — tag a genre or leave it blank to auto-detect one.
  4. Your creators, genres, and key are all saved in this browser, so they'll be here next time.
  5. Opened this file directly (double-clicked it)? Videos will open on YouTube in a new tab instead of the pop-up player — YouTube blocks its embedded player from pages loaded that way.
Getting a free YouTube API key
  1. Go to console.cloud.google.com and sign in with any Google account.
  2. Create a new project — the name doesn't matter, anything works.
  3. Use the search bar at the top and search for "YouTube Data API v3", open it, and click Enable.
  4. Go to APIs & Services → Credentials → Create Credentials → API key. Google will generate a key — copy it.
  5. Click Edit API key to set restrictions (recommended, not required): under "Application restrictions" choose None, and under "API restrictions" choose Restrict key and select just YouTube Data API v3. Save.
  6. Paste the key into the box below and hit Save key. That's it — no billing setup needed, and the free daily quota is far more than enough for personal use.
