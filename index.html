How Anti Algo works
  1. Get a free YouTube API key. It's a one-off job that takes about five minutes, and it's what lets this site fetch videos from YouTube for you. Press Get a free key in the box at the bottom of the page and it will walk you through it.
  2. Paste your key into the API Key box and press Save key.
  3. Add creators you already follow. Paste a channel's link or @handle into the box at the top and press Add creator. Give them a genre if you like, or leave it blank and one is suggested for you.
  4. Watch. Their latest videos appear newest first. Click a video to play it, or click a creator's name (or a genre) to see just those.
  5. It's all saved in your browser, so it will be here next time. No account needed.
What's an API key, and why do I need one?

YouTube lets other websites ask it for information, such as "what are this creator's newest videos?", through something called an API. Think of it as a service hatch: this site places the order, and YouTube hands over the answer.

An API key is your personal pass for using that hatch. It's what lets this site fetch the feed of the creators you choose. Without one, YouTube won't answer, so your feed would stay empty.

  • It's free. No payment details are needed, and the free allowance is far more than you'll use.
  • It's private. Your key is saved only in your own browser. Nobody else can see or use it.
  • It's read-only. It can only look up public YouTube information. It can't post, comment or touch your account.
Get your key (1 of 3)
  1. Press Set up with Google below and sign in with any Google account.
  2. Google asks you to choose a project. Pick Create a new project. Any name works.
  3. Press Enable. This switches on YouTube Data API v3 for you.
Get your key (2 of 3)
  1. Open Credentials and press Create credentials.
  2. For "Which API are you using?" keep YouTube Data API v3. For "What data will you be accessing?" choose Public data, then continue.
  3. Name the key API key.
  4. Under Select API restrictions, open the dropdown, type YouTube Data API v3, tick it and press OK.
Get your key (3 of 3)
  1. Under Key restrictions, choose Websites, press Add and paste this address: https://your-site-address/*
  2. Press Create and copy the key Google shows you.
  3. Paste it into the API Key box at the bottom of this page and press Save key.

Keep a copy in a password manager or notes app, so it's easy to paste on another device. If you lose it, sign in to Google Cloud Console, go to APIs & Services → Credentials and open your key to see it again.
