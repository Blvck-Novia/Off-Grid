ANTI ALGO
Latest uploads from your favourite creators

Anti Algo is a small, personal tool for watching YouTube on your own terms. There's no algorithm deciding what you see next and no autoplay pulling you into a rabbit hole, just the latest uploads from creators you chose, in the order they were actually posted.

The basics

It's a self-contained web page that pulls the latest videos from a list of YouTube creators you pick, and shows them to you in one simple feed, sorted purely by upload date and nothing else. There's no "recommended for you," no trending tab, no algorithm nudging you toward anything. If you didn't add the creator, you won't see their videos.

YouTube's homepage and "Up Next" queue are built to maximise watch time, and they're very good at keeping you watching things you didn't plan to watch. Anti Algo flips that: you decide the full list of creators up front, and that's all you'll ever see here. It's a way to keep up with people you actually follow without wading through everything else YouTube wants to show you.

The API key

An API key is like a personal password that lets this page ask YouTube directly for data, like the latest videos from a channel, thumbnails and titles, through YouTube's official Data API. Without a key, YouTube has no way to know who's asking or whether the request is legitimate, so it won't respond. The key is free, tied to your own Google account, and only this page (running in your browser) ever uses it.

Yes, completely free for normal personal use. Google gives every API key a free daily quota (10,000 units), and just browsing your feed uses a tiny fraction of that. No billing details are required to create the key, and nothing here could rack up charges even if you left it running all day.

Head back to the home page and click the "Get a free key" button next to the API key box at the bottom. It walks through the whole process step by step, from creating a free Google Cloud project to pasting the finished key in.

Your key is stored only in your own browser and is never sent anywhere except directly to Google's API. If you're sharing this page with other people (say, via a hosted link), each person needs to get and enter their own key. Keys are never shared between visitors, and nobody can see yours.

Keep a copy somewhere safe, like a password manager or a notes app. If you lose it, sign in to Google Cloud Console with the same Google account, go to APIs & Services, then Credentials, and open your key to see it again. On a new device, just paste it into the API Key box and press Save key.
